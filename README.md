# CyberWealth

CyberWealth es una aplicación para el control de finanzas personales construida con Nuxt 3 y Tailwind CSS.

## Características
- Registro y visualización de ingresos y gastos
- Componentes reutilizables y diseño moderno
- Experiencia de usuario optimizada para dispositivos móviles y escritorio

## Tecnologías
- [Nuxt 3](https://nuxt.com/)
- [Tailwind CSS](https://tailwindcss.com/)

## Instalación

Asegúrate de instalar las dependencias:

```bash
npm install
```

## Desarrollo

Inicia el servidor de desarrollo en `http://localhost:3000`:

```bash
npm run dev
```

## Producción

Construye la aplicación para producción:

```bash
npm run build
```

Previsualiza la build de producción localmente:

```bash
npm run preview
```

Para más información, consulta la [documentación de Nuxt](https://nuxt.com/docs/getting-started/introduction).
